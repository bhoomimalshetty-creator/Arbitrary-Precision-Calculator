# Arbitrary-Precision-Calculator
APC is a C-based calculator that performs arithmetic operations on very large numbers beyond the limits of standard C data types. It uses doubly linked lists to store digits and supports addition, subtraction, multiplication, division, and modulus operations.

## Features

- Performs arithmetic operations on large numbers
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Supports positive and negative numbers
- Uses doubly linked lists for storing digits
- Dynamic memory allocation

## Technologies Used

- C Programming
- Data Structures
- Doubly Linked Lists
- Dynamic Memory Allocation
- Linux
- Makefile
